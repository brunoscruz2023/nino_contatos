# Manual do Usuário - Painel de Lideranças

Bem-vindo ao aplicativo de gestão de território e eventos. Este manual irá guiá-lo pelas funcionalidades do sistema, explicando o que você pode fazer em cada tela de acordo com o seu perfil de acesso (Básico, Supervisor ou Gestor).

## 1. Primeiros Passos: Acessando o Sistema
Para acessar o sistema, utilize o seu Telefone ou a sua Chave de Acesso.
*   **Primeiro Acesso:** Se o seu gestor acabou de cadastrar você, sua senha inicial será padrão (`123456`). Ao digitar essa senha pela primeira vez, o sistema identificará que é um acesso inicial e abrirá uma tela para você **criar sua própria senha**.
*   **Regra de Segurança:** Sua nova senha deve ter 6 dígitos numéricos e não pode ser igual à senha padrão. Após a troca, você terá acesso liberado ao aplicativo.

## 2. Navegação: Menu Inferior e Botão Flutuante (FAB)
*   **Menu Inferior:** É a barra de navegação na base da tela. O sistema é inteligente e sempre esconde o ícone da tela em que você já está para liberar espaço. Além disso, ele prioriza os módulos de gestão caso você tenha acesso a muitas funções.
*   **Botão Flutuante (FAB):** É o botão circular no centro da barra inferior. Ele se adapta à tela em que você está usando. Por exemplo, se você estiver no mapa, ele abre a busca. Se você abrir um evento na agenda, ele se transforma no botão de Check-in.

## 3. Módulo Mapa (Território)
**Objetivo:** Visualizar a distribuição geográfica dos contatos e lideranças por bairro.
Dependendo do seu perfil de acesso, você verá diferentes informações ao expandir os bairros na lista:
*   **Acesso Básico:** Você verá apenas os bairros e a quantidade de contatos em cada um, sem exibir os nomes.
*   **Acesso com WhatsApp:** Você verá a lista de nomes e poderá clicar diretamente no ícone do WhatsApp para iniciar uma conversa.
*   **Acesso Completo:** Você verá todos os dados dos contatos (telefone, referência) e poderá clicar nos nomes para editar as informações.
*   **Filtros:** No topo, use os filtros de Região, Equipe e Função para isolar os dados que você deseja visualizar no momento.

## 4. Módulo Agenda (Eventos e Tarefas)
**Objetivo:** Acompanhar suas escalas de campo e registrar presenças.
*   **Atuantes (Campo):** Você verá apenas os eventos dos quais participa. Para registrar a presença de um participante, **expanda o card do evento** na tela. Ao fazer isso, o Botão Flutuante (FAB) no canto inferior mudará para um ícone de "Check-in" (Confirmar). Clique nele para abrir a tela de cadastro de presença. É possível registrar presenças de eventos passados.
*   **Supervisores:** Você terá os botões "+ Evento" e "+ Tarefa" disponíveis para criar novas escalações. Ao criar uma tarefa avulsa para alguém, o sistema exigirá o telefone do responsável para garantir que a tarefa chegue à pessoa certa.

## 5. Módulo Cadastro
**Objetivo:** Incluir novos contatos na base de dados de forma rápida.
*   Informe o telefone do novo contato. Se o número já existir, o sistema carregará os dados para você atualizar. Se for novo, os campos serão liberados.
*   **Seleção de Equipe:** Ao cadastrar, você pode selecionar mais de uma equipe para o contato (ex: se a pessoa atua com a equipe Carlos e Veronica simultaneamente). Basta clicar no campo de Equipe e marcar as caixas correspondentes. Se você só pertencer a uma equipe, ela já virá preenchida.

## 6. Gestão de Acessos e Materiais (Para Gestores)
**Objetivo:** Configurar usuários e controlar a logística da campanha.
*   **Gestão de Usuários:** Busque um contato pelo telefone. Se ele não estiver cadastrado, o sistema oferecerá a opção de cadastrar e, em sequência, abrir a tela de permissões para definir o que esse usuário poderá acessar no app.
*   **Logística de Materiais:** O controle de materiais funciona como um funil de pendências.
    1. O Gestor registra a **Entrada** de itens no estoque.
    2. O Distribuidor entrega os itens a um mobilizador, gerando uma pendência.
    3. O Mobilizador recebe a notificação no app e deve **confirmar o recebimento** para dar baixa no sistema.
*   *Nota:* Usuários que possuem acesso à Gestão de Acessos não veem o botão de "Cadastro" no menu inferior, pois o fluxo de cadastro já está embutido na própria tela de gestão.

## 7. Módulo Dashboard (Painel Gerencial)
**Objetivo:** Acompanhamento de métricas em tempo real.
Se você tiver acesso a esta tela, verá gráficos e números divididos em abas (você só verá as abas referentes aos módulos que possui acesso):
*   **Operação:** Mostra eventos de hoje, total de presentes e os eventos com maior público.
*   **Território:** Mostra o crescimento de novos contatos no mapa e o ranking de bairros que mais cresceram.
*   **Logística:** Mostra o saldo atual de estoque de materiais, quantos estão em trânsito e quem mais recebeu materiais no período.
*   **Filtros de Período:** Use os botões no topo (Hoje, 7 Dias, 30 Dias) para alterar o período de análise dos gráficos.
