```markdown
# Ajuda Rápida

### Mapa
- **Como ver contatos:** Toque no bairro no mapa ou na lista para expandir.
- **Filtros:** Use as opções no topo da tela para filtrar por região, equipe ou função.
*(Exibir apenas se o usuário tiver acesso ao Mapa)*

### Agenda
- **Meus eventos:** Toque no dia do calendário para ver o que está agendado.
- **Check-in de Presença:** Abra o card do evento. O botão flutuante (FAB) no canto inferior mudará para um "Check-in" verde. Toque nele para cadastrar quem compareceu.
- **Tarefas:** Tarefas avulsas aparecem no calendário. Abra o card para ver a descrição e clique em "Concluir Tarefa" quando terminar.
*(Exibir apenas se o usuário tiver acesso à Agenda)*

### Cadastro
- **Novo contato:** Digite o telefone. Se for novo, preencha os dados. Se já existir, os dados carregarão automaticamente.
- **Equipes:** Toque no campo de Equipe para marcar mais de uma caixa, se o contato atuar em mais de uma equipe.
*(Exibir apenas se o usuário tiver acesso ao Cadastro E NÃO tiver acesso ao Admin)*

### Admin
- **Configurar usuário:** Busque pelo telefone. Se não encontrar, toque em "Cadastrar Novo Contato".
- **Permissões:** Marque o nível de acesso para cada módulo (Mapa, Agenda, etc.) e salve. O usuário precisará fazer logout e login para as alterações surtirem efeito.
*(Exibir apenas se o usuário tiver acesso ao Admin)*

### Materiais
- **Receber material:** Quando alguém te entregar material, aparecerá uma notificação de pendência. Toche nela e confirme o recebimento para dar baixa no sistema.
*(Exibir apenas se o usuário tiver acesso a Materiais)*

### Dashboard (Painel)
- **Métricas:** Toque nas abas no topo para alternar entre Operação (Eventos), Território (Mapa) e Logística (Materiais).
- **Período:** Use os botões (Hoje, 7 dias, 30 dias) para mudar o período de análise dos gráficos.
*(Exibir apenas se o usuário tiver acesso ao Dashboard)*
```
